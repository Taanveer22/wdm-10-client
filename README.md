# 🌸 Orchid Movie Portal

A full-stack MERN-based movie management web application where users can explore, add, and manage movies while maintaining a personalized favorites list. The platform features secure authentication, dynamic search, and user-specific data handling for a smooth and interactive experience.

---

## 🚀 Live Demo

👉 https://orchid-movie-portal-2707d.web.app/

---

## 📄 Project Overview

**Orchid Movie Portal** allows users to:

- Browse a collection of movies
- Add and manage their own movies
- Maintain a personalized favorites list
- Search movies dynamically
- Access secure, authenticated features

---

## ✨ Features

### 🔐 Authentication System

- Firebase authentication
- Google login support
- Protected/private routes
- Auth state persistence with loading spinner
- User profile update (name & photo/logo)

---

### 🎬 Movie Management

- Add new movies
- View all movies
- View detailed movie information
- Delete movies from collection
- Featured movies section

---

### ❤️ Favorites (User-Specific)

- Add movies to favorites
- View favorite movies per user
- Delete individual favorite movies
- Google login favorite issue resolved

---

### 🔍 Search Functionality

- Real-time search from UI
- Case-insensitive movie filtering

---

### ⭐ Rating System

- Interactive star rating using `react-simple-star-rating`

---

### 🎨 UI/UX Enhancements

- Responsive modern UI with Tailwind CSS + DaisyUI
- Banner slider using Swiper.js
- SweetAlert2 for beautiful alerts & confirmations
- Loading spinner for async operations

---

### 🌐 Deployment

- Client deployed on Firebase
- Server deployed on Vercel
- Fully integrated client-server architecture
